## Adding a plan

Once a plan has been carried out, add it here as `YYYY-MM-DD-<topic>.md`, using the date it was
planned. Each file has three parts:

1. A header saying the file is a historical record, with the planned and carried-out dates and
   links to the PRs.
2. The approved plan, unchanged.
3. An `## Outcome` section covering what was done, what changed from the plan and why, and what
   was left open.
